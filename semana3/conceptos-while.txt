Responde con tus propias palabras.

1. ¿Qué significa repetir instrucciones en programación?

Respuesta: ejecutar varias veces un conjunto de instrucciones de forma automatica

2. ¿Qué es un ciclo while?

Respuesta: repite instrucciones mientras una condicion es verdadera

3. ¿Qué significa la condición dentro de un while?

Respuesta: es una exprexion que evalua como verdadera o falsa 

4. ¿Por qué es importante cambiar una variable dentro del while?

Respuesta: permite que la condicion deje de cumplirse y el ciclo termine

5. ¿Qué es un ciclo infinito?

Respuesta: un buqle que se repite sin fin

6. ¿Qué hace el comando npm run practicar?

Respuesta: ejecutar el nodo siclo while.js

7. ¿Dónde está definido el comando practicar?

Respuesta: package.json

8. ¿Qué diferencia hay entre node archivo.js y npm run practicar?

Respuesta: js lo que escribimos, node.js lo que ejecutamos y npm run  automatiza la ejecucion

9. ¿Cómo puede servir un while para revisar varias fuentes de información?

Respuesta: sirve para revisar varias fuentes de informacion por que integra y compara datos de diferentes lugares para dar un resumen unificado y mas claro 

10. ¿Cómo puede relacionarse un ciclo con el seguimiento de propuestas comunitarias?

Respuesta: se relaciona con el segimiento  de propuestas comunitarias por que permite revisar cada propuesta de forma ordena y repetida hasta completar toda la revision
